## Usage

The funnel chart is composable. `<NQFunnelChart>` compiles an ECharts <Link href="https://echarts.apache.org/en/option.html#series-funnel" _blank>`series-funnel`</Link> from ordered stage rows (`stageKey`) and values (`valueKey`). Default layout is vertical trapezoids; set `orient="horizontal"` for left→right stages, or `connection="pipe"` for a smooth S-curve ribbon (horizontal by default, or `orient="vertical"`). Compose `<Stages />`, `<Tooltip />`, and `<Legend />` as needed.

```tsx
import {
  NQFunnelChart,
  Stages,
  XAxis,
  YAxis,
  Grid,
  Tooltip,
  Legend,
} from "@/components/nqchart/charts/funnel-chart";
```

```tsx
<NQFunnelChart
  config={chartConfig}
  data={funnelRows}
  stageKey="stage"
  valueKey="amount"
  backgroundVariant="dots"
>
  <YAxis />
  <XAxis />
  <Stages isClickable glowingStages={["trials"]} />
  <Grid />
  <Tooltip />
  <Legend isClickable />
</NQFunnelChart>
```

### Interactive Selection

Add `isClickable` to `<Stages />` (plus `<Legend />` when you want swatches clickable) then listen on `onSelectionChange` (`{ dataKey, value } | null`). `dataKey` matches rows’ `stageKey` string:

```tsx
<NQFunnelChart
  config={chartConfig}
  data={funnelRows}
  stageKey="stage"
  valueKey="amount"
  onSelectionChange={(selection) => {
    if (selection) {
      console.log("Selected:", selection.dataKey, selection.value);
    } else {
      console.log("Deselected");
    }
  }}
>
  <YAxis />
  <XAxis />
  <Stages isClickable />
  <Legend isClickable />
  <Tooltip />
</NQFunnelChart>
```

### Pipe (smooth ribbon)

Ribbon with tight S-curve fillets **only at joins between levels** (outer ends are square; previous level stays flat until near the edge). Defaults horizontal; set `orient="vertical"` for top→bottom. Optional `turnRadius` (px half-width of each join — keep small, e.g. `6`).

```tsx
<NQFunnelChart data={rows} config={config} connection="pipe">
  <Stages connection="pipe" turnRadius={6} />
  <Tooltip />
</NQFunnelChart>

<NQFunnelChart data={rows} config={config} connection="pipe" orient="vertical">
  <Stages connection="pipe" orient="vertical" turnRadius={6} />
  <Tooltip />
</NQFunnelChart>
```

## API Reference

The chart is composed of several parts. The props below are grouped by the component they belong to.

<ApiHeading>NQFunnelChart</ApiHeading>

Root container. Compiles ECharts `series-funnel` (or a custom pipe series when `connection="pipe"`). Holds stage metadata and synthesized loading rows when `isLoading`.

<ApiTable>
  <ApiRow name="config" type="Record<string, ChartConfig[string]>" required>
    Keys must match `stageKey` values so colors and legend labels resolve per stage.
  </ApiRow>
  <ApiRow name="data" type="TData[]" required>
    Rows with `stageKey` + numeric `valueKey` fields.
  </ApiRow>
  <ApiRow name="stageKey" type="string" default='"stage"'>
    Field name for the stage identifier.
  </ApiRow>
  <ApiRow name="valueKey" type="string" default='"value"'>
    Field name for numeric throughput (scales stage size).
  </ApiRow>
  <ApiRow name="children" type="ReactNode" required>
    `<Stages />`, `<Tooltip />`, `<Legend />`, and optional axis stubs.
  </ApiRow>
  <ApiRow name="className" type="string">
    Additional wrapper classes forwarded to `<ChartContainer />`.
  </ApiRow>
  <ApiRow name="orient" type='"vertical" | "horizontal"'>
    Flow direction. Native funnel defaults `vertical`; pipe defaults `horizontal` when unset. Both support pipe.
  </ApiRow>
  <ApiRow name="sort" type='"ascending" | "descending" | "none"' default='"none"'>
    Native funnel stage order. Default `none` keeps the `data` array order (pipeline stages stay put when a mid-stage outgrows an earlier one). Unused for `pipe`.
  </ApiRow>
  <ApiRow name="connection" type='"seamless" | "default" | "segmented" | "pipe"' default='"default"'>
    Stage join style. `pipe` switches to the smooth S-curve ribbon renderer.
  </ApiRow>
  <ApiRow name="taper" type='"soft" | "default" | "steep"' default='"default"'>
    How gradually native funnel stage sizes taper (`minSize`). Unused for `pipe`.
  </ApiRow>
  <ApiRow name="stageGap" type="number">
    Pixel gap between stages — overrides the `connection` preset gap. Unused for `pipe`.
  </ApiRow>
  <ApiRow name="turnRadius" type="number">
    Pipe mode: half-width of the S-curve level-change zone in px. Omit for half-a-stage-width transitions.
  </ApiRow>
  <ApiRow name="isLoading" type="boolean" default="false">
    Swaps rendered rows with shimmer placeholders while awaiting data.
  </ApiRow>
  <ApiRow name="hoverFocus" type="boolean" default="true">
    Hover dim: focused stage full opacity, siblings at `0.2`. `false` keeps the tooltip and disables sibling fade. See [Hover Focus](/docs/hover-focus).
  </ApiRow>
</ApiTable>

<ApiHeading>Stages</ApiHeading>

Style slot for connection, taper, orient, and turn radius (same props as the root; child values win when set).

<ApiTable>
  <ApiRow name="connection" type='"seamless" | "default" | "segmented" | "pipe"'>
    Stage join preset. `pipe` = smooth horizontal ribbon.
  </ApiRow>
  <ApiRow name="orient" type='"vertical" | "horizontal"'>
    Native funnel orientation.
  </ApiRow>
  <ApiRow name="sort" type='"ascending" | "descending" | "none"'>
    Native funnel stage order (wins over root when set).
  </ApiRow>
  <ApiRow name="taper" type='"soft" | "default" | "steep"'>
    Native funnel size taper.
  </ApiRow>
  <ApiRow name="stageGap" type="number">
    Pixel gap override for native funnel.
  </ApiRow>
  <ApiRow name="turnRadius" type="number">
    Pipe S-curve half-width in px.
  </ApiRow>
  <ApiRow name="isClickable" type="boolean" default="false">
    Reserved for stage click selection (legend still handles clickable swatches).
  </ApiRow>
</ApiTable>

<ApiHeading>XAxis</ApiHeading>

Mirrors numeric scale even though NQFunnel hides ticks by default to keep silhouette clean (`hide` maps to ECharts axis visibility).

<ApiTable>
  <ApiRow name="hide" type="boolean" default="true">
    Default hides axis line / ticks consistent with NQFunnels marketing aesthetic.
  </ApiRow>
  <ApiRow name="type" type='"number" | ...' default='"number"'>
    Forwarded verbatim to `<XAxis />` while loading states hide axes automatically.
  </ApiRow>
  <ApiRow name="…axisProps">
    Additional xAxis options are merged into the compiled ECharts option. Read the <Link href="https://echarts.apache.org/en/option.html#xAxis" _blank>ECharts xAxis</Link> documentation for available props.
  </ApiRow>
</ApiTable>

<ApiHeading>YAxis</ApiHeading>

Shows ordered funnel stages (category axis for vertical funnel layout).

<ApiTable>
  <ApiRow name="width" type="number" default="96">
    Default tick gutter width accommodating stage labels before trapezoid math runs.
  </ApiRow>
  <ApiRow name="type" type='"category" | ...' default='"category"'>
    Drives categorical placement for each funnel row (`dataKey={stageKey}` internally).
  </ApiRow>
  <ApiRow name="…axisProps">
    Additional yAxis options are merged into the compiled ECharts option. Read the <Link href="https://echarts.apache.org/en/option.html#yAxis" _blank>ECharts yAxis</Link> documentation for available props.
  </ApiRow>
</ApiTable>

<ApiHeading>Grid</ApiHeading>

Optional vertical-only dashed scaffolding for alignment reference.

<ApiTable>
  <ApiRow name="strokeDasharray" type="string" default='"3 3"'>
    Dash pattern forwarded to `<CartesianGrid />`.
  </ApiRow>
  <ApiRow name="…gridProps">
    Horizontal lines stay disabled intentionally; remaining grid options are merged into the compiled ECharts option. Read the <Link href="https://echarts.apache.org/en/option.html#grid" _blank>ECharts grid documentation</Link> for nuance.
  </ApiRow>
</ApiTable>

<ApiHeading>Tooltip</ApiHeading>

Disables Cartesian cursor crosshair (`cursor={false}`) for cleaner funnel hovering.

<ApiTable>
  <ApiRow name="variant" type='"default" | "frosted-glass"' default='"default"'>
    Tooltip polish tier.
  </ApiRow>
  <ApiRow name="roundness" type='"sm" | "md" | "lg" | "xl"' default='"lg"'>
    Tooltip radius.
  </ApiRow>
  <ApiRow name="defaultIndex" type="number">
    Pre-highlights tooltip for a deterministic stage row while pointer idle.
  </ApiRow>
</ApiTable>

<ApiHeading>Legend</ApiHeading>

Stage keyed legend syncing dimming + selection mirrored from `<Stages />`.

<ApiTable>
  <ApiRow name="variant" type='"square" | "circle" | "circle-outline" | "rounded-square" | "rounded-square-outline" | "vertical-bar" | "horizontal-bar"'>
    Legend marker motifs.
  </ApiRow>
  <ApiRow name="align" type='"left" | "center" | "right"' default='"center"'>
    Horizontal alignment.
  </ApiRow>
  <ApiRow name="isClickable" type="boolean" default="false">
    Legend entries toggle shared selection; dimming follows `selectedStage` even when `<Stages />` is not clickable.
  </ApiRow>
</ApiTable>
