## Usage

The pie chart is composable. `<NQPieChart>` is the container, and you compose only the parts you need — `<Legend>`, `<Tooltip>`, and one `<Pie>` — as its children. The `<Pie>` carries the shape: `innerRadius` for a donut, `rose` for a Nightingale rose, `sort`, `showLabels`.

Every pie follows the NQChart signature: an even seam between slices (`--chart-gap`, 2px — not the wedge-shaped gap of a pad angle) and rounded slice corners (11px), with labels on two-leg leader lines that never overlap. Set `gap={0}` and `cornerRadius={0}` on `<Pie>` for classic touching wedges.

```tsx
import { NQPieChart, Pie, Tooltip, Legend } from "@/components/nqchart/charts/pie-chart";
```

```tsx
const data = [
  { browser: "chrome", visitors: 275 },
  { browser: "safari", visitors: 200 },
  { browser: "firefox", visitors: 187 },
];

const chartConfig = {
  chrome: {
    label: "Chrome",
    colors: { light: ["#3b82f6"], dark: ["#60a5fa"] },
  },
  safari: {
    label: "Safari",
    colors: { light: ["#10b981"], dark: ["#34d399"] },
  },
  firefox: {
    label: "Firefox",
    colors: { light: ["#f59e0b"], dark: ["#fbbf24"] },
  },
} satisfies ChartConfig;
```

```tsx
<NQPieChart data={data} nameKey="browser" config={chartConfig}>
  <Legend isClickable />
  <Tooltip />
  <Pie dataKey="visitors" nameKey="browser" innerRadius="40%" />
</NQPieChart>
```

### Interactive Selection

Add `isClickable` to `<Legend>` to isolate a slice from the legend (the others fade to `0.2`); `selected` / `onSelectChange` make it controlled. Use `onMarkClick` on `<NQPieChart>` to react to a slice click:

```tsx
<NQPieChart
  data={data}
  nameKey="browser"
  config={chartConfig}
  onMarkClick={(event) => console.log("Clicked:", event.seriesKey, event.datum)}
>
  <Legend isClickable onSelectChange={(key) => console.log("Isolated:", key)} />
  <Tooltip />
  <Pie dataKey="visitors" nameKey="browser" />
</NQPieChart>
```

### Rose

`<Pie rose="radius">` draws a Nightingale rose: each slice's angle **and** length follow its value, sorted largest first and running clockwise from 12 o'clock. Slices use the NQChart signature — an even seam between slices (`--chart-gap`, 2px) and rounded corners (the surface radius, 11px) — and the drawn shape is fitted to the card. `rose="area"` gives every slice the same angle and varies only the length. For equal-angle petals on a polar axis, see the radial chart's `radialLayout="rose"`.

<ComponentPreview title="Rose" name="ex-pie-rose-chart" />

```tsx
<NQPieChart data={data} nameKey="channel" config={config}>
  <Legend />
  <Tooltip />
  <Pie dataKey="visits" nameKey="channel" rose="radius" />
</NQPieChart>
```

## API Reference

The chart is composed of several parts. The props below are grouped by the component they belong to.

<ApiHeading>NQPieChart</ApiHeading>

The root container. It owns the data, the shared selection state, and the loading skeleton. Everything visual is composed as its children.

<ApiTable>
  <ApiRow name="data" type="TData[]" required>
    Data used to display the chart. An array of objects where each object represents a sector (`TData extends Record<string, unknown>`).
  </ApiRow>
  <ApiRow name="nameKey" type="keyof TData & string">
    The key from your data objects to use for sector names (typically string values used for labels and legend).
  </ApiRow>
  <ApiRow name="config" type="ChartConfig" required>
    Configuration object that defines the chart's sectors. Each key should match a value from your `nameKey` field, with corresponding colors.
  </ApiRow>
  <ApiRow name="children" type="ReactNode" required>
    The composed chart parts — `<Legend />`, `<Tooltip />`, and one `<Pie />`.
  </ApiRow>
  <ApiRow name="className" type="string">
    Additional CSS classes to apply to the chart container.
  </ApiRow>
  <ApiRow name="hoverFocus" type="boolean" default="true">
    Hover dim: focused slice full opacity, siblings at `0.2`. `false` keeps the tooltip and disables sibling fade. See [Hover Focus](/docs/hover-focus).
  </ApiRow>
  <ApiRow name="onMarkClick" type="(event: NQMarkEvent) => void">
    Fired when a slice is clicked, with the slice key and its source row. Also turns on arrow-key navigation across slices.
  </ApiRow>
  <ApiRow name="isLoading" type="boolean" default="false">
    Shows a loading placeholder animation when data is being fetched.
  </ApiRow>
</ApiTable>

<ApiHeading>Pie</ApiHeading>

The pie series. Slices run clockwise from 12 o'clock and use the NQChart signature geometry — an even seam and rounded corners.

<ApiTable>
  <ApiRow name="dataKey" type="string" default='"value"'>
    The field holding each slice's value.
  </ApiRow>
  <ApiRow name="nameKey" type="string">
    The field naming each slice (matches a `config` key). Defaults to the root `nameKey`.
  </ApiRow>
  <ApiRow name="innerRadius" type="number | string" default='0 (rose: "12%")'>
    Hole radius — px, or `"NN%"` of half the shorter side. Greater than 0 makes a donut.
  </ApiRow>
  <ApiRow name="outerRadius" type="number | string" default='"65%" (rose: "92%")'>
    Rim radius — px, or `"NN%"` of half the shorter side. A rose without labels is fitted to the card when this is unset.
  </ApiRow>
  <ApiRow name="showLabels" type="boolean" default="true (rose: false)">
    Slice names outside the rim on two-leg leader lines, spread so they never overlap. Slices under 3° skip their label; the tooltip still names them.
  </ApiRow>
  <ApiRow name="rose" type='"radius" | "area"'>
    Draw a Nightingale rose. `"radius"` — slice angle and length both follow the value; `"area"` — equal angles, length follows the value.
  </ApiRow>
  <ApiRow name="sort" type='"descending" | "ascending" | "none"' default='"none" (rose: "descending")'>
    Slice order, clockwise from 12 o'clock.
  </ApiRow>
  <ApiRow name="gap" type="number" default="--chart-gap (2)">
    The even seam between slices, in pixels. `0` makes slices touch.
  </ApiRow>
  <ApiRow name="cornerRadius" type="number" default="11">
    Slice corner radius in pixels. Corners shrink to fit thin slices; corners at the hole scale with it. `0` gives sharp wedges.
  </ApiRow>
</ApiTable>

<ApiHeading>Tooltip</ApiHeading>

The hover tooltip. Hidden automatically while the chart is loading.

<ApiTable>
  <ApiRow name="variant" type='"default" | "frosted-glass"' default='"default"'>
    The visual style of the tooltip surface.
  </ApiRow>
  <ApiRow name="roundness" type='"sm" | "md" | "lg" | "xl"' default='"lg"'>
    Controls the border-radius of the tooltip.
  </ApiRow>
  <ApiRow name="defaultIndex" type="number">
    When set, the tooltip is visible by default at the specified sector index.
  </ApiRow>
</ApiTable>

<ApiHeading>Legend</ApiHeading>

The sector legend. When `isClickable` is set, each entry toggles selection of its sector.

<ApiTable>
  <ApiRow name="variant" type='"square" | "circle" | "circle-outline" | "rounded-square" | "rounded-square-outline" | …'>
    The visual style of the legend indicators.
  </ApiRow>
  <ApiRow name="align" type='"left" | "center" | "right"' default='"center"'>
    Horizontal placement of the legend.
  </ApiRow>
  <ApiRow name="isClickable" type="boolean" default="false">
    Lets each legend entry toggle selection of its sector.
  </ApiRow>
</ApiTable>
