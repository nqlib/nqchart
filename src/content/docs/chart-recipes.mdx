BI-style charts are built from **primitives** plus small data helpers in `chart-recipes`. Install the helpers once via the shadcn registry, then compose the matching `NQ*Chart` as documented on each chart page.

## Installation

<CliBlock commands={["@nqchart/chart-recipes"]} />

This runs `shadcn add` and copies `lib/chart-recipes.ts` into your project. Chart components are installed separately (e.g. `@nqchart/bar-chart`).

## Helpers

| Helper | Use with | Doc examples |
|--------|----------|----------------|
| `binForHistogram(values, binCount?)` | `NQBarChart` | [Bar chart](/docs/bar-chart/static) → Histogram |
| `prepareBulletRow(label, { actual, target, max? })` | `NQBarChart` `layout="horizontal"` | [Bar chart](/docs/bar-chart/static) → Bullet chart |
| `prepareParetoData(rows, nameKey, valueKey)` | `NQComposedChart` | [Composed chart](/docs/composed-chart/static) → Pareto |
| `prepareBoxPlotRow(category, samples)` | `NQComposedChart` stacked bars + line | [Composed chart](/docs/composed-chart/static) → Box plot |
| `prepareHeatmapCells(rowLabels, colLabels, matrix)` | `NQHeatmapChart` | [Heatmap chart](/docs/heatmap-chart/static) |
| `workloadUtilization(assigned, available)` | any workload view | Returns utilization % |
| `prepareCalendarWorkloadCells(days)` | `NQCalendarChart` | [Calendar chart](/docs/calendar-chart/static) → Employee workload |
| `prepareTeamWorkloadMatrix(dates, rows)` | `NQHeatmapChart` | [Calendar chart](/docs/calendar-chart/static) → Team workload |
| `normalizeGaugeValue(value, min?, max?)` | `NQRadialChart` `variant="semi"` | [Radial chart](/docs/radial-chart/static) → Gauge with target |
| `prepareGaugeRows({ score, target?, … })` | `NQRadialChart` `nameKey="series"` | Same — `series` keys must match `chartConfig` |
| `prepareVarianceRows(rows, { categoryKey, actualKey, planKey, higherIsBetter? })` | `NQComposedChart` signed bars | [Variance](#variance-actual-vs-plan) |
| `prepareCohortCells(rows, { cohortKey, periodKey, valueKey, mode? })` | `NQHeatmapChart` | [Cohort retention](#cohort-retention) |
| `prepareForecastSeries(rows, { dateKey, actualKey, forecastKey, lowerKey, upperKey })` | `NQComposedChart` line + `RangeArea` | [Forecast band](#forecast-band) |
| `prepareDumbbellRows(rows, { categoryKey, fromKey, toKey })` | `NQComposedChart` `Connector` + dots | [Slope / dumbbell](#slope--dumbbell) |

```tsx
  prepareGaugeRows,
  prepareVarianceRows,
  prepareCohortCells,
  prepareForecastSeries,
  prepareDumbbellRows,
} from "@/lib/chart-recipes";
```

Inside this repo, examples use `@/registry/lib/chart-recipes`.

## Variance (actual vs plan)

`prepareVarianceRows()` returns `actual`, `plan`, `delta`, `deltaPct` and `good` per category. `deltaPct` is `null` when the plan is 0 or missing; `good` is `null` when there is no delta. Set `higherIsBetter: false` for cost-like measures. Split `delta` into two keys (`favorable` / `unfavorable`) and stack them under one `stackId` so each bar keeps its slot and the colours follow `chartConfig`; a solid `<ReferenceLine y={0} />` marks the baseline and `showLabels` prints the signed Δ.

## Cohort retention

`prepareCohortCells()` turns long rows (`cohort`, `period`, `value`) into a triangle for `<Heatmap />`. In `percent` mode period 0 is 100; cohorts sort ascending and periods a cohort has not reached are left out, not zero. `xLabels` are `M0…Mn`. A category y-axis draws its first label at the bottom, so pass `[...yLabels].reverse()` to put the oldest cohort on top.

## Forecast band

`prepareForecastSeries()` splits a series at the last row with an actual value: `actual` stops there, `forecast` starts on the same point so the lines join, and `lower` / `upper` (plus `band: [lower, upper]`) pinch to the actual at the join. Draw `<Line dataKey="actual" />`, `<Line dataKey="forecast" variant="dashed" />`, `<RangeArea lowKey="lower" highKey="upper" />` and a `<ReferenceLine x="…" label="Today" />`.

## Slope / dumbbell

`prepareDumbbellRows()` returns `from`, `to`, `delta` and `direction` per category, sorted by `delta` descending (ties keep input order). On `<NQComposedChart />` pair `<Connector fromKey="from" toKey="to" />` with two `<Line variant="dots" />` series — round markers at the signature point size, no line. Composed charts are category-x, so the dumbbell is vertical.

## When not to add a new chart file

If the visualization only changes **data shape** or **props** on an existing primitive, extend `chart-recipes` and add an `ex-*` example on the primitive doc page — do not create a separate `NQHistogramChart` package.
