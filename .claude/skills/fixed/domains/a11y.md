# Domain: a11y

Screen-reader data tables (`ChartA11yTable`) must look up columns that exist on
the **rows**, not keys that only exist for colour in `config`.

## Fixes

- [pie table blank](../fixes/a11y-pie-table-blank.md)

## When investigating

1. Cartesian rows are `{ [xDataKey]: category, [seriesKey]: number | null }`. Config keys are series keys. `deriveSeriesKeysFromConfig` is correct there; `null` stays an empty cell (not `"0"`).
2. Pie (and similar name/value) rows are `{ name, value }` while config is keyed by **slice name**. Do not reuse the cartesian helper.
3. Funnel may share the name/value + config-by-stage pattern — check before copying cartesian keys.
